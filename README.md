# 口腔知情同意书生成器（Dental Consent Workbench）

一个**纯前端、零后端**的口腔治疗知情同意书在线生成工具。所有数据只保存在使用者的浏览器本地（localStorage），不上传任何服务器，天然满足患者隐私要求。

**在线使用**：https://kyring151.github.io/dental-consent-forms/

## ✨ 功能

- **四个项目模板**：牙体树脂充填、根管治疗、牙拔除术、固定冠修复，条款依据 2024–2025 年公开临床指南与专家共识整理
- **条款级编辑**：每条可勾选显隐、点击改字、追加自定义条款；关键风险条款标红，取消勾选需二次确认
- **预览直编**：A4 预览里的条款可直接点入修改，回车在条款内换行，双向同步
- **物理分页预览**：逐张 A4 白纸预览，跨页章节自动补「（续）」标题，列表编号跨页连续
- **版式设置**：患者信息栏字段可增删改、列宽可在预览中拖拽调整；签字区行、横线长度可编辑
- **全文排版**：字号、字色在线调整（关键风险条款红色不变）
- **Logo 页眉**：上传诊所 Logo 显示在文书首页左上角（≤2MB，自动压缩，仅存本地）
- **打印 / 导出 PDF**：逐张精确导出，无空白页；页码水印、拖拽手柄等辅助元素不会进入正式文书
- **草稿自动保存**：条款、版式、Logo 全部本地持久化，刷新不丢

## 🚀 本地运行

```bash
npm run dev        # 默认 http://127.0.0.1:7100/，支持 --port / --host 参数
```

或直接双击 `index.html` 用浏览器打开（推荐 Chrome / Edge）。

## 📁 结构

```
index.html            入口
css/style.css         界面与文书样式（屏幕 / 打印两套）
js/templates.js       模板库（新增项目 = 追加一份结构化配置）
js/app.js             主逻辑（条款编辑 / 分页渲染 / PDF 导出 / Logo）
lib/                  html2canvas + jsPDF（本地，离线可用）
assets/icons/         项目缩略图
server.js             极简静态服务器（仅本地预览用）
```
